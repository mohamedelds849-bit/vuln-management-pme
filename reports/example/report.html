6. Méthode

Scanner : Trivy (images et dépendances). Enrichissement : CISA KEV (vulnérabilités exploitées, catalogue 2026.10.08) et FIRST EPSS (probabilité d'exploitation sous 30 jours, modèle v2026.06.15). Décision inspirée de SSVC (CISA) : exploitation (KEV / EPSS ≥ 10 % / autre) × exposition de l'actif (Internet / interne / isolé) × impact (CVSS ≥ 9.0 total, ≥ 7.0 élevé) × criticité métier → P1 Agir / P2 Traiter / P3 Planifier / P4 Suivre, avec un délai (SLA) par niveau : P1 7 j, P2 30 j, P3 90 j, P4 180 j. Répartition brute du scanner : CRITICAL 76, HIGH 1349, MEDIUM 6020, LOW 1950, UNKNOWN 145. Limites : le scanner ne voit que les paquets connus (pas la configuration, pas le code maison) ; EPSS est une probabilité, pas une certitude ; une CVE absente du KEV peut quand même être exploitée.
